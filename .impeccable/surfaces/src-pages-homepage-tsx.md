# Home and application shell

- Scope: the home surface and the global shell that governs every workflow.
- Mode: Operate.
- Audience: everyday privacy users moving files between two nearby devices.
- Job: choose Send or Receive immediately and understand that the file crosses directly through visible light, never a server.
- Primary action: Send a file; Receive is an equally prominent reciprocal action.
- Proof: the existing screen-to-camera mechanism, local-only operation, browser capability state, and real LOTP workflow.
- Constraints: preserve Russian/English switching, every existing workflow, keyboard access, mobile usability, and current technical claims only.
- Chosen world: the category standard, executed at the craft level of LocalSend and Alaqan—plain confidence, oversized language, controlled rounded framing, and clear product proof.
- Memorable moment: a visible optical path joins the Send and Receive endpoints without turning the app into a technical dashboard.
- Approved composition: `.impeccable/mocks/comp-b-optical-window.png` (“Optical window”).
- Component grammar: one dominant 28px-radius proof window; plain white shell; dark working panels; thin separators; solid primary controls; no nested card field.
- Type ramp: Onest variable, 400–800; display 64–72px desktop / 42–48px mobile, compact line-height; UI 14–16px.
- Elevation: the hero uses one soft, downward shadow; working panels use borders without shadows.
- Inventory:
  - Navigation and language control — semantic HTML, Lucide icons.
  - Headline and Send/Receive actions — semantic HTML.
  - Laptop-to-camera optical scene — generated WebP asset, text-free.
  - Three-step transfer strip — semantic HTML and Lucide icons.
  - Browser capability state — live React content from `CapabilityChecker`.
  - Optical pulse — bounded CSS motion with reduced-motion fallback.
